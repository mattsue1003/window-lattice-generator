# 窗櫺紋紙本生成器

老房子、廟宇木窗上的吉祥花樣，一鍵產生 A4 紙本：欣賞、上色、剪紙、做卡片。

- 10 種窗櫺紋：冰裂紋、冰裂梅花、步步錦、龜背錦、八角錦、燈籠錦、回紋、方勝紋、直櫺窗、方格窗
- 6 種窗形：方窗、圓窗（月洞）、八角窗、海棠窗、拱門窗、扇形窗
- 版面：1 大窗／2 扇門窗／4 小窗／6 張卡片
- 呈現：木窗彩色（5 種木色）、線稿上色、剪紙版
- 中央圓光可放吉祥字（福、壽、春、喜、安或自訂）
- 輸出：列印、PDF、可編輯 PPT、SVG

線上使用：https://mattsue1003.github.io/window-lattice-generator/
